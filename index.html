무료 열쇠 받는 방법
  1. 휴대폰 크롬에서 aistudio.google.com 에 들어가 구글 계정으로 로그인해요.
  2. 약관에 동의하고 「Get API key」(API 키 받기)를 눌러요.
  3. 「Create API key」를 누르면 AIza… 로 시작하는 글자가 나와요. 복사해요.
  4. 여기 칸에 붙여넣고 「저장」→「시험해 보기」를 눌러요.
